# v0.8.5 — Bug fixes, daily reset at 08:00 KST, browser build parity

Everything that landed between v0.8.4 and the web-app release (v0.9.0),
which had not been written up. Native iOS/watchOS app and the browser build.

## Fixed

- **Evolution refusing to trigger with every stat full.** The real cause
  was a dangling-reference bug in the `min()`/`max()` shim (`Sources/Core/
  Arduino.h`): with identical argument types the ternary yielded a reference
  to a temporary, so `lowestStat()` could read garbage and report a stat
  as below 40. Fixed with a `std::decay` return type. Verified in the
  Simulator by driving real taps.
- **Stats decaying while the Evolve / Farewell dialog was open**, so a
  stat just above the threshold could dip below it before you tapped
  Evolve. The clock now freezes while a decision dialog is up (iOS and
  browser); the dialog's silent 12-second auto-close is gone.
- **Wild battle:** the "already caught" marker on the encounter prompt,
  win/loss criteria, and DEF/SPD training results that were not applied.
- **Training sack** strength gain not applied; **Memo** minigame's DEF
  gain raised 2.5×.
- **After a battle from the stat card you stay on the stat card** instead
  of being thrown back to the idle screen; tap-to-close on the card now
  only answers the back tab, not any tap.
- **Watch: the cry button** works.
- **Daily goals** (and every once-a-day system: streak, daily caps,
  morning greeting) now roll over at **08:00 Korean time** instead of
  midnight UTC, and re-sync every five minutes while the app is open so a
  long-running session sees the new day.
- **Egg rarity label** ("Rare egg!" / "Legendary egg!?") was painted and
  then covered by the panel fill, so it never showed on iOS. Draw order
  fixed.

## Browser build

Brought to visual parity with the iOS app — same TPIcon pixel glyphs
(buttons, berries, candy, poop, heart), the same SceneRenderer backdrop
(sky by hour, biome ground, night palette) behind idle/minigames/battle,
the creature's stroll/gesture scheduler and the CLEAN bath, the egg with
cracks and hint, the four-item FEED menu, streak badge, level-up banner,
header status line, long-press release dialog, caress zone, and the
wild-battle "already caught" marker. Real sprites for the wild opponent
and the dex portrait; dex cry playback with a "Load cries…" picker; real
swipe navigation matching iOS.

## Docs

The illustrated HTML guides were merged into the markdown guides;
screenshots embedded there.

# v0.8.5 — 버그 수정, 일일 초기화 08:00 KST, 브라우저 빌드 동일화

v0.8.4와 웹앱 릴리스(v0.9.0) 사이에 들어갔지만 기록되지 않았던 내용 전부.
네이티브 iOS/watchOS 앱과 브라우저 빌드.

## 수정

- **스탯이 전부 꽉 차 있어도 진화가 안 되던 문제.** 진짜 원인은 `min()`/`max()`
  셰임(`Sources/Core/Arduino.h`)의 댕글링 참조 버그였습니다. 인자 타입이 같으면
  삼항 연산자가 임시값의 참조를 돌려줘서 `lowestStat()`가 쓰레기 값을 읽고
  스탯을 40 미만으로 보고할 수 있었습니다. `std::decay` 반환 타입으로 수정.
  시뮬레이터에서 실제 탭을 넣어 검증.
- **진화/작별 대화상자가 떠 있는 동안 스탯이 계속 줄어서** 기준 바로 위의
  스탯이 버튼을 누르기 전에 아래로 떨어질 수 있던 문제. 결정 대화상자가 떠
  있는 동안 시계를 멈춤(iOS·브라우저). 대화상자가 12초 뒤 조용히 닫히던
  동작 제거.
- **야생 배틀:** 조우 프롬프트의 "이미 잡음" 표시, 승/패 판정 기준, 적용되지
  않던 방어/속도 훈련 결과.
- **훈련 자루** 힘 상승이 적용되지 않던 문제; **패턴 기억** 미니게임의 방어
  상승량 2.5배.
- **스탯 카드에서 배틀한 뒤 스탯 카드에 그대로 남음**(대기 화면으로 튕기지
  않음). 카드의 탭해서 닫기는 아무 곳이 아니라 뒤로 탭에만 반응.
- **워치: 울음소리 버튼** 동작.
- **일일목표**(및 연속일·일일 상한·아침 인사 등 하루 단위 시스템 전부)가
  UTC 자정이 아니라 **한국시간 오전 8시**에 넘어가고, 앱을 켜둔 상태에서도
  5분마다 재동기화해 날짜 변경을 반영.
- **알 희귀도 라벨**("희귀한 알!" / "전설의 알!?")을 그린 뒤 패널로 덮어
  그려서 iOS에서 한 번도 안 보이던 문제. 그리기 순서 수정.
