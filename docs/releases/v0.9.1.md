# v0.9.1 — Web app parity pass: starter picker, save files, Korean UI, iOS-matched screens

Everything reported from the first days on the phone build, fixed in one
round. No change to the iOS/watchOS app.

## Fixed

- **Starter picker was missing** — a fresh save went straight to the egg
  and hatched a random classic starter. The picker (three trios, one
  generation per page, language pill) is now ported; and the automatic
  reload the service worker used to trigger on first install — which
  threw away a starter picked seconds earlier — is gone. Starter picks and
  egg taps are saved immediately.
- **Idle screen drew only the backdrop** (no bars, no buttons, no
  creature) — a missing `streak` binding threw mid-draw and killed the
  rest of the frame. Draw errors are now shown in the status line instead
  of freezing on "loading…".
- **Language reset to English on every launch** — the choice was saved but
  never read back at startup (`loadLang()`).
- **Long-pressing the creature** (the release dialog) triggered iOS text
  selection / the magnifier over the game.
- **Farewell and runaway showed a silhouette** for the whole ceremony;
  now the real sprite bows / flinches and walks off, silhouette only on
  the runaway's blink frames, as on iOS. Ceremonies and evolution draw
  over the habitat scene.
- **Stat bar labels invisible at night** (day ink on the dark panel).
- **Expedition inventory** empty slots were black; now the same light
  panel as iOS. Box pager disabled colour likewise.

## Changed (parity with the iOS app)

- Minigames redrawn to the iOS layout: score/record/lives header, memo's
  round pads with pulse rings and the phase line, type quiz's coloured
  buttons, countdown bars (including the training sack, which had none),
  result cards with the stat gain line.
- Battle-page buttons (Wild battle / Train strength) and the evolve /
  farewell choice dialog at the iOS coordinates; text vertically centred in
  every button.
- Korean (and every other UI language) now covers the play menu, minigame
  titles, score / record / round lines, memo prompts, need-bar labels,
  sound-mode pill, Pokédex filters and header, and the rename title.
- Pokédex detail portrait plays the idle animation.
- **`thumbs.bin` is read** (pick it with "Load sprites…"): the Pokédex grid
  shows the atlas thumbnail for every species — ink silhouettes for ones
  you haven't seen, like the iOS app — instead of "?".
- Sound starts on (FULL); the browser still waits for the first tap.
- Toolbar (Load sprites / dex text / cries, Save file, Load save, Reset
  game) sits above the game instead of floating over it.

## New

- **Save file… / Load save…** — export the save as `iTamaPoke-save.tpsave`
  to the Files app (put it in your `mons` folder) and restore it later or
  on another phone. **Reset game…** wipes the save and starts a new egg,
  keeping sprites. The web app cannot write into the Files app by itself,
  so this is the equivalent of the iOS app's `iTamaPoke-save.json`.

## Docs

- Install guides rewritten around diagrams: path chooser, Path D flow,
  icon / save / files relationship, "Building the mons folder" (what each
  file is, where it comes from, where it goes), shiny fetch time, Apple
  Watch device-registration rules, per-symptom troubleshooting tables.
- Recommendation order: D (web/Android) → C (Xcode) → B (signed) → A.

# v0.9.1 — 웹앱 동일화 패스: 스타터 선택, 세이브 파일, 한글 UI, iOS와 같은 화면

폰 빌드를 처음 며칠 써보며 나온 보고를 한 번에 정리했습니다. iOS/watchOS
앱은 변경 없음.

## 수정

- **스타터 선택 화면이 없었음** — 새 세이브가 바로 알로 가서 랜덤 스타터가
  부화했습니다. 선택 화면(세대별 3마리, 세대별 페이지, 언어 알약)을 포팅했고,
  첫 설치 때 서비스 워커가 일으키던 자동 새로고침(방금 고른 스타터를 날려
  버리던 원인)을 없앴습니다. 스타터 선택과 알 두드리기는 즉시 저장.
- **대기 화면에 배경만 그려짐**(바·버튼·캐릭터 없음) — `streak` 바인딩 누락
  예외가 그리기 중간에 나서 이후를 전부 건너뛰었습니다. 이제 그리기 오류는
  상태 줄에 표시되고 "loading…"에서 멈추지 않습니다.
- **켤 때마다 영어로 초기화** — 언어는 저장됐지만 시작 시 읽어오지 않았음
  (`loadLang()`).
- **캐릭터 길게 누르기**(놓아주기 대화상자)에서 iOS 텍스트 선택/돋보기가
  게임 위에 뜨던 문제.
- **작별·가출 연출이 실루엣만** — 이제 실제 스프라이트가 인사/움찔하고 걸어
  나가며, 가출의 깜빡임 프레임에만 실루엣(iOS와 동일). 연출·진화는 서식지
  장면 위에 그림.
- **밤에 스탯 바 라벨이 안 보임**(어두운 패널에 낮 잉크색).
- **원정 가방** 빈 칸이 검은색 → iOS와 같은 밝은 패널. 박스 페이지 비활성
  버튼 색도 동일.

## 변경 (iOS 앱과 동일화)

- 미니게임을 iOS 배치로 다시 그림: 점수/기록/목숨 헤더, 패턴 기억의 원형
  패드·펄스 링·단계 문구, 타입 퀴즈의 색 버튼, 카운트다운 바(없던 힘 훈련
  포함), 능력치 증가 줄이 있는 결과 카드.
- 배틀 페이지 버튼(야생 배틀/힘 훈련)과 진화/작별 선택 대화상자를 iOS
  좌표로; 모든 버튼 글씨 세로 중앙 정렬.
- 한글(및 모든 UI 언어)이 놀이 메뉴, 미니게임 제목, 점수/기록/라운드, 패턴
  기억 안내문, 바 라벨, 사운드 알약, 도감 필터·헤더, 이름 변경 제목까지
  적용.
- 도감 상세 초상화가 대기 동작을 재생.
- **`thumbs.bin`을 읽음**("Load sprites…"로 함께 선택): 도감 격자에 종별 아틀라스
  썸네일이 나오고, 아직 못 본 종은 iOS 앱처럼 검은 실루엣으로 표시("?" 대신).
- 소리 기본 켜짐(FULL). 브라우저 규칙상 첫 탭 뒤부터 남.
- 툴바(스프라이트/도감문/울음소리 불러오기, Save file, Load save, Reset
  game)를 게임 위에 떠 있던 방식에서 게임 위쪽 영역으로 이동.

## 새로 추가

- **Save file… / Load save…** — 세이브를 `iTamaPoke-save.tpsave`로 파일
  앱에 내보내고(`mons` 폴더에 두면 됨) 나중에 또는 다른 폰에서 복원.
  **Reset game…**은 세이브만 지우고 새 알부터 시작(스프라이트 유지). 웹앱은
  파일 앱에 스스로 쓸 수 없으므로 iOS 앱의 `iTamaPoke-save.json`에 해당하는
  기능입니다.

## 문서

  세이브/파일 관계도, "mons 폴더 구성하기"(파일별 정체·출처·위치), 이로치
  소요 시간, 애플워치 기기 등록 규칙, 증상별 문제 해결 표.
