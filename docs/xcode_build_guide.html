iTamaPoke · 빌드 가이드

Xcode로 내 기기에 직접 빌드하기

이 문서는 iTamaPoke 저장소를 받아서 본인의 아이폰과 애플워치에 설치하기까지 전체 과정을 그림과 함께 순서대로 보여줍니다. GitHub Actions로 받은 .ipa를 사이드로딩하는 방법이 아니라, Xcode로 직접 빌드해서 케이블로 설치하는, 워치까지 확실하게 되는 경로입니다.

§1먼저: 어느 경로로 갈지 정하기

계정 종류가 아니라, "워치까지 필요한가"로 갈리는 갈림길입니다.

무료 Apple ID

이 가이드 그대로

  • 비용 없음
  • 워치 설치 이 방법으로만 확실함
  • 유효기간 7일마다 ⌘R로 재실행
유료 Developer ($99/년)

GitHub Actions 서명 빌드도 대안

  • CI가 서명까지 끝낸 .ipa 배포 가능
  • 워치도 정상 설치됨
  • 1년 유효 — 자세한 차이는 DEV_ACCOUNT.md

둘 중 무엇을 갖고 있든 이 가이드(Xcode 직접 빌드)는 항상 통합니다 — 무료 계정은 사실 이 방법 말고는 워치 설치가 거의 안 되기 때문에, 이 문서는 무료 계정 기준으로 설명합니다.

§2준비물

  • Mac (Xcode가 설치된) — Apple Silicon/Intel 무관
  • Xcode (App Store)
  • Apple ID 하나 (무료면 충분, 워치까지 이 방법이 제일 확실함)
  • 본인 아이폰, 애플워치 (USB 케이블로 최초 1회 연결)

§3순서대로 따라하기

  1. 저장소 받기

    서브모듈(upstream/)까지 함께 받아야 게임 로직이 포함됩니다.

    git clone --recurse-submodules <저장소 주소>
cd iTamaPoke
  2. 캐릭터 스프라이트 넣기 (선택)

    안 해도 빌드는 됩니다 — 캐릭터 자리에 "No sprites" 표시만 나옵니다.

    Scripts/fetch_sprites.sh 1 4 7   # 스타터 3종만
# 또는
Scripts/fetch_sprites.sh all    # 151종 전체, 약 20MB
    참고 — 이 파일들은 git에 올라가지 않습니다(.gitignore). 개인 기기에 빌드하는 용도로만 존재합니다. 라이선스 참고.
  3. Xcode 프로젝트 생성하기
    brew install xcodegen
xcodegen generate
open TamaPoke.xcodeproj

    .xcodeproj는 매번 새로 만들어지는 파일이라 커밋되어 있지 않습니다 — 이 명령을 실행할 때마다 생성됩니다.

  4. 두 기기 모두 개발자 모드 켜기

    아이폰과 애플워치 각각: 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켜기 → 재시작. 워치는 별도 토글이라 아이폰에서 켰다고 워치까지 켜지지 않습니다.

  5. 서명 설정하기

    Xcode에서 TamaPoke 타겟 선택 → Signing & Capabilities → Automatically manage signing 체크 → 본인 Apple ID(팀) 선택. TamaPokeWatch 타겟도 똑같이, 반드시 같은 팀으로.

    주의 — xcodegen generate를 다시 돌리면 이 설정이 초기화됩니다. 재생성할 때마다 팀을 다시 선택하세요.
  6. 아이폰에 설치

    USB로 연결 → 기기에서 신뢰 탭 → TamaPoke 스킴, 본인 아이폰을 대상으로 선택 → ⌘R.

    첫 실행 시 한 번만: 아이폰 설정 → 일반 → VPN 및 기기 관리 → 개발자 인증서 신뢰. 이걸 안 하면 앱이 안 열립니다.

  7. 애플워치에 설치

    TamaPokeWatch 스킴, 본인 애플워치를 대상으로 선택 → ⌘R. 워치는 잠금 해제 상태로 충전기에 꽂아두세요 — 처음 설치는 몇 분씩 걸리고 멈춘 것처럼 보이는 게 정상입니다.

  8. (선택) 아이콘 바꾸기

    아무것도 안 하면 기본 마스코트 아이콘이 자동으로 들어갑니다. 본인 이미지로 바꾸려면:

    Scripts/fetch_app_icon.sh path/to/icon.png
xcodegen generate

§47일마다 해야 하는 것

무료 Apple ID의 유일한 단점입니다.

무료 Apple ID로 서명한 앱은 7일이 지나면 실행이 멈춥니다. 다시 쓰려면 기기를 Mac에 연결하고 같은 스킴으로 ⌘R을 한 번 더 누르면 됩니다 — 새로 설치하는 게 아니라 서명만 갱신되는 것이라 게임 데이터는 그대로 남습니다. 유료 Developer Program은 1년까지 갱신 없이 유지됩니다.

§5막히는 지점 정리

워치에 안 깔려요. Xcode로 직접 설치하는 이 방법이 아니라면(사이드로딩 등) 거의 항상 워치 앱이 빠집니다. 이 가이드대로 TamaPokeWatch 스킴을 따로 실행했는지 확인하세요.

"신뢰할 수 없는 개발자" 라고 떠요. §3의 6번, 인증서 신뢰 단계를 건너뛴 경우입니다.

다른 사람 계정으로 이미 등록된 번들 ID라고 나와요. project.yml의 PRODUCT_BUNDLE_IDENTIFIER를 본인만의 값으로 바꾸세요.

전체 배경 설명은 저장소의 README를, 게임 자체 설명은 게임 방법을 참고하세요.
